# 收藏 API 参考

## stars.list — 列出收藏项

| 参数 | 必填 | 说明 |
|------|------|------|
| limit | 否 | 返回数量 |

## stars.create — 收藏文档

| 参数 | 必填 | 说明 |
|------|------|------|
| documentId | 是 | 文档 ID |

## stars.delete — 取消收藏

| 参数 | 必填 | 说明 |
|------|------|------|
| id | 是 | 收藏记录 ID（从 `stars.list` 获取，非文档 ID） |
