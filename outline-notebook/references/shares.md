# 分享 API 参考

## shares.list — 列出所有分享

| 参数 | 必填 | 说明 |
|------|------|------|
| limit | 否 | 返回数量 |

## shares.info — 获取分享详情

| 参数 | 必填 | 说明 |
|------|------|------|
| id | 是 | 分享 ID |

## shares.create — 创建分享链接

| 参数 | 必填 | 说明 |
|------|------|------|
| documentId | 是 | 文档 ID |

返回 `url` 字段为公开分享链接。

## shares.update — 更新分享设置

| 参数 | 必填 | 说明 |
|------|------|------|
| id | 是 | 分享 ID |
| includeChildDocuments | 否 | 是否包含子文档 |
| published | 否 | 是否公开 |

## shares.delete — 撤销分享

| 参数 | 必填 | 说明 |
|------|------|------|
| id | 是 | 分享 ID |

撤销前需与用户确认。
